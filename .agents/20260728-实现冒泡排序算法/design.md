## 1. 需求范围分析

### 1.1 需求描述

实现一个冒泡排序（Bubble Sort）算法：对一组可比较的元素按升序进行原地（in-place）排序。

- **输入**：一个可比较元素组成的数组/列表。
- **输出**：按升序排列的同一数组（原地修改，不返回新数组或返回同一引用）。
- **核心机制**：重复地比较相邻两个元素，若顺序错误则交换，使每轮把当前未排序段的最大值“冒泡”到末尾。

### 1.2 范围界定（IN / OUT）

| 类别 | 说明 |
|------|------|
| ✅ IN（本次实现） | 冒泡排序核心算法、相邻比较与交换、提前终止优化（无交换即有序）、泛型可比较类型支持、基本单元测试 |
| ❌ OUT（本次不做） | 其他排序算法（快排/归并等）、降序排序（可扩展但非默认）、多线程/并行排序、大数据集生产级优化、与外部系统/数据库/接口集成 |

### 1.3 验收标准

1. 给定任意整数数组，排序后为严格升序。
2. 原地排序，排序后传入数组本身即有序（不依赖返回值新建数组）。
3. 空数组、单元素数组不报错，直接返回。
4. 已有序数组在开启优化时仅执行一轮比较即终止（O(n) 最佳）。
5. 含重复元素的数组能正确排序且保持稳定性（相等元素相对顺序不变）。
6. 对含 `null` 元素的输入明确抛出 `NullPointerException`（不静默吞掉，遵循 fail-fast）。

## 5. 功能模块设计

### 5.1 算法核心逻辑

外层循环控制轮数（`n-1` 轮），内层循环在每轮未排序段 `[0, n-1-i)` 内比较相邻元素并按需交换。每轮结束后当前未排序段最大值沉至末位。

### 5.2 提前终止优化

每轮开始前置 `swapped = false`；若该轮无任何交换，说明数组已全局有序，直接 `break` 退出外层循环。

### 5.3 伪代码

```
function sort(arr):
    if arr == null: throw NullPointerException
    n = arr.length
    for i from 0 to n-2:                    // 外层 n-1 轮
        swapped = false
        for j from 0 to n-2-i:              // 内层比较到 n-1-i
            if arr[j] > arr[j+1]:          // 相邻逆序
                swap(arr[j], arr[j+1])
                swapped = true
        if not swapped: break              // 本轮无交换，已有序
```

### 5.4 关键边界条件

| 场景 | 处理 |
|------|------|
| `arr == null` | 抛 `NullPointerException` |
| `arr.length == 0`（空数组） | 外层循环不进入，直接返回 |
| `arr.length == 1`（单元素） | 外层循环条件 `i <= n-2 = -1` 不满足，直接返回 |
| 全部有序 | 第 1 轮 `swapped` 保持 `false`，`break`，O(n) |
| 全部逆序 | 最坏情况，执行满 `n-1` 轮，O(n²) |
| 含重复元素 | `>`（严格大于）判定使相等元素不交换，保持稳定性 |

### 5.5 实现代码（参考实现）

```java
package com.example.sort;

/**
 * 冒泡排序工具类（原地、稳定、泛型）。
 */
public final class BubbleSorter {

    private BubbleSorter() {
        // 工具类，禁止实例化
    }

    /**
     * 对可比较元素数组进行原地升序冒泡排序。
     *
     * @param arr 待排序数组，元素须实现 Comparable；不允许为 null 或含 null 元素
     * @param <T> 可比较元素类型
     * @throws NullPointerException 数组或其元素为 null 时抛出
     */
    public static <T extends Comparable<? super T>> void sort(T[] arr) {
        if (arr == null) {
            throw new NullPointerException("arr must not be null");
        }
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < n - 1 - i; j++) {
                // 严格大于：相等不交换，保证稳定性
                if (arr[j].compareTo(arr[j + 1]) > 0) {
                    T tmp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = tmp;
                    swapped = true;
                }
            }
            if (!swapped) {
                break; // 本轮无交换，数组已有序
            }
        }
    }
}
```

## 6. 非功能需求

### 6.1 性能（时间复杂度）

| 情况 | 复杂度 | 触发条件 |
|------|--------|----------|
| 最佳 | O(n) | 数组已有序（开启提前终止优化，仅 1 轮） |
| 平均 | O(n²) | 随机分布数据 |
| 最坏 | O(n²) | 数组完全逆序 |

### 6.2 空间复杂度

- O(1)：原地排序，仅使用常数级临时变量 `tmp` 与 `swapped` 标志。

### 6.3 稳定性

- **稳定排序**：采用严格大于（`> 0`）判定，相等元素不交换，相对顺序保持不变。

### 6.4 适用性与限制

- 适用于小规模数据或基本有序数据；大规模数据应换用 O(n log n) 算法（本次范围外）。

### 6.5 可测试性

- 静态纯函数，无副作用、无状态，易于参数化单测覆盖。
