一、模块概述
--------------------------------------------------------------------------------
模块名称: document-module（文档模块）
技术栈: TypeScript + Node.js（Kanban 本地应用）
存储方案: 本地文件系统 + JSON 索引
编码格式: UTF-8
单文档上限: 1MB

二、存储结构设计
--------------------------------------------------------------------------------
存储根目录: {kanban_data_dir}/documents/

目录结构:
  documents/
  ├── index.json          # 文档索引（元数据）
  ├── {uuid1}.txt         # 文档内容文件
  ├── {uuid2}.txt
  └── ...

索引文件 index.json 结构:
  {
    "version": 1,
    "documents": [
      {
        "id": "uuid-v4-string",
        "title": "文档标题",
        "fileName": "{id}.txt",
        "taskId": "关联任务ID | null",
        "createdBy": "创建者",
        "createdAt": "ISO 8601",
        "updatedAt": "ISO 8601",
        "size": 1234
      }
    ]
  }

三、API 接口清单
--------------------------------------------------------------------------------
编号  | 方法  | 路径                    | 说明
------|-------|-------------------------|-----------------------
W01   | POST  | /api/document/create    | 创建文档
W02   | GET   | /api/document/get       | 获取文档内容
W03   | POST  | /api/document/update    | 更新文档
W04   | POST  | /api/document/delete    | 删除文档
W05   | GET   | /api/document/list      | 文档列表（分页）
W06   | GET   | /api/document/search    | 搜索文档

四、错误码定义
--------------------------------------------------------------------------------
DOC_000  成功
DOC_001  参数校验失败（标题为空 / 内容超 1MB）
DOC_002  磁盘写入失败
DOC_003  文档不存在
DOC_004  文件读取失败

五、核心业务逻辑
--------------------------------------------------------------------------------

5.1 创建文档 (F01)
  - 校验: 标题非空, 内容 ≤ 1MB
  - 生成 UUID v4 作为文档 ID
  - 写入 {id}.txt 到文件系统
  - 更新 index.json 索引
  - 返回文档元数据

5.2 获取文档 (F02)
  - 校验: documentId 为有效 UUID
  - 从 index.json 读取元数据
  - 从 {id}.txt 读取内容
  - 返回完整文档信息

5.3 更新文档 (F03)
  - 校验: 文档存在, 内容 ≤ 1MB
  - 至少提供 title 或 content 之一
  - 更新磁盘文件 + 索引
  - 最后写入覆盖（last-write-wins）

5.4 删除文档 (F04)
  - 校验: 文档存在
  - 删除磁盘文件
  - 清理索引记录
  - 容错: 文件和索引不一致时自动修复

5.5 文档列表 (F05)
  - 分页查询索引
  - 支持按 taskId 筛选
  - 默认每页 20 条，最大 100 条

5.6 搜索文档 (F06)
  - 关键词匹配标题（索引内完成）
  - 内容搜索需逐文件读取
  - 分页返回结果

六、非功能性设计
--------------------------------------------------------------------------------
- 原子写入: 先写临时文件，再 rename 覆盖
- 索引容错: 启动时自动检测并重建
- 日志: 关键操作 INFO 级别，异常 ERROR 级别
- Feature Flag: document.enabled / document.searchEnabled

七、并发控制
--------------------------------------------------------------------------------
- 多标签页: 最后写入覆盖（last-write-wins）
- UUID: 保证文档 ID 唯一性
- 索引写入: 原子 write-then-rename
