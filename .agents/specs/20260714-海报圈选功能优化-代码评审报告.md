## 4. 代码评审建议

### 4.1 数据库层面

```sql
-- 建议新增字段示例
ALTER TABLE poster_selection_rule ADD COLUMN dimension_type VARCHAR(20) COMMENT '圈选维度: STORE/DEVICE';
ALTER TABLE poster_selection_rule ADD COLUMN selection_values JSON COMMENT '批量ID列表';
```

### 4.2 接口层面

- **批量查询接口**：建议增加 `batch_size` 参数，默认10，最大20
- **活动校验接口**：建议返回活动名称、状态、有效期，便于前端回显
- **黑白名单修改接口**：建议增加 `operator_id` 和 `operation_type` 参数用于日志记录

### 4.3 业务逻辑层面

```java
// 黑白名单优先级建议逻辑
public boolean isDeviceAllowed(String deviceId, PosterSelectionRule rule) {
    if (rule.getDeviceWhitelist().contains(deviceId)) {
        return true; // 白名单优先
    }
    if (rule.getDeviceBlacklist().contains(deviceId)) {
        return false; // 黑名单拦截
    }
    return rule.isGlobalSelectionEnabled(); // 默认遵循全局圈选
}
```
