# 海报圈选功能优化规格文档

## 1. 需求背景

随着N大促多类活动并行，对海报圈选能力和叠加规则有了更多的要求，本次核心优化点：
1. 圈选黑白名单支持门店和设备维度多选
2. 黑白名单需要在前置发布时支持配置
3. 查询详情时需要展示圈选维度
4. 图灵ID支持批量粘贴
5. 活动ID支持校验，与奖品ID一样可以校验出活动名称

---

## 2. 功能清单

| 模块 | 具体需求 |
|------|----------|
| 新建/编辑投放计划 | 投放范围：全局圈选支持多维度及多选，和批量粘贴能力；支持黑白名单配置；立减活动信息支持查询回显 |
| 查看投放计划 | 圈选、活动信息支持查看 |

---

## 3. 详细需求

### 3.1 新建/编辑投放计划

#### 3.1.1 投放范围 - 图灵圈选

**全局圈选**
- 原图灵圈选功能迁移
- 包含 bizTid 和数字化门店ID
- 右侧提示：去图灵平台创建，超链接跳转
- 支持多选

**设备黑名单**
- 从发布管理的添加黑白名单功能迁移
- 包含 bizTid 和数字化门店ID
- 右侧提示：去图灵平台创建，超链接跳转
- 支持多选

**设备白名单**
- 从发布管理的添加黑白名单功能迁移
- 包含 bizTid 和数字化门店ID
- 右侧提示：去图灵平台创建，超链接跳转
- 支持多选

#### 3.1.2 输入交互

**输入方式**
- 选择类型后，展示输入框
- 小字提示：「若有多个圈选，使用英文逗号分隔，系统自动识别」
- 输入时前端校验：若存在英文逗号分隔，自动识别为多个人群ID

**数量限制**
- 最多支持20个
- 前端分页展示

**查询展示**
- 点击查询后，下方展示图灵人群信息：
  - bizTid
  - 标签名称
  - 设备数量
  - 标签有效期
- 若有多个ID，展示「查看更多」

**黑白名单交互**
- 设备黑白名单交互逻辑与全局圈选同理
- 支持在发布后二次修改
- 回显创建时配置的信息

#### 3.1.3 中心化立减进度小程序 & 整点立减活动海报

**活动ID配置**
- 配置立减ID
- 支持查询活动信息
- 输入后下方展示活动信息

---

### 3.2 查看投放计划

- 投放范围同创编页
- 支持全部查看
- 圈选、活动信息支持查看

---

## 4. 数据字段

### 4.1 圈选配置

| 字段 | 类型 | 说明 |
|------|------|------|
| bizTid | String | 图灵人群ID |
| digitStoreId | String | 数字化门店ID |
| labelName | String | 标签名称 |
| deviceCount | Number | 设备数量 |
| validityPeriod | Date | 标签有效期 |

### 4.2 黑白名单配置

| 字段 | 类型 | 说明 |
|------|------|------|
| type | Enum | black/white |
| bizTid | String | 图灵人群ID |
| digitStoreId | String | 数字化门店ID |

### 4.3 立减活动信息

| 字段 | 类型 | 说明 |
|------|------|------|
| activityId | String | 活动ID |
| activityName | String | 活动名称 |
| prizeId | String | 奖品ID |

---

## 5. 接口需求

### 5.1 查询图灵人群信息
- 入参：bizTid 列表（最多20个）
- 出参：bizTid、标签名称、设备数量、标签有效期

### 5.2 校验活动ID
- 入参：activityId
- 出参：activityName

### 5.3 保存投放计划
- 包含全局圈选、设备黑名单、设备白名单配置
- 包含立减活动ID

### 5.4 查询投放计划详情
- 回显所有圈选配置
- 回显活动信息

---

## 6. 验收标准

1. 全局圈选、设备黑名单、设备白名单均支持多选（最多20个）
2. 支持批量粘贴（英文逗号分隔）
3. 黑白名单支持前置配置，支持发布后二次修改
4. 查询详情正确展示圈选维度
5. 活动ID校验可返回活动名称
6. 查看投放计划页面正确展示所有配置信息

---

## 7. 风险点

1. 图灵平台接口稳定性 - 需要确认超时处理和降级方案
2. 批量查询性能 - 20个ID批量查询需要考虑接口性能
3. 黑白名单二次修改 - 需要确认权限控制和操作日志
