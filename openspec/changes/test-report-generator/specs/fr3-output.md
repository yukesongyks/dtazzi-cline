# Spec: 输出格式与落盘 (FR3)

## 功能概述
报告支持多种输出格式，默认 Markdown，落盘路径可配置。

## 格式支持

### FR3.1 输出格式
| 格式 | 优先级 | 说明 |
|------|--------|------|
| Markdown | P0（默认） | 人类可读，适合 Git 归档 |
| HTML | P1 | 适合邮件/浏览器查看 |
| JSON | P1 | 结构化数据，伴随产物 |

### FR3.2 落盘路径
- 默认：`reports/test-report-<YYYYMMDD-HHmmss>.md`
- 用户可通过 `output_path` 覆盖目录
- 目录不存在时自动创建

### FR3.3 生成后返回
- 报告绝对路径
- 结果摘要（通过率、失败数）
- 失败时附最关键 1~3 条失败原因

## 验收标准
- 默认路径生成 Markdown 报告
- 指定 `output_path` 后写入正确位置
- 返回信息包含路径 + 摘要
